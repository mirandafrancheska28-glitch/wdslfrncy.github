MY PERSONAL PORTFOLIO WEBSITE
Files:
- index.html: Home
- about.html: About Me and Skills
- projects.html: Projects
- contact.html: Contact form
- styles.css: Shared responsive styling
- script.js: Active navigation and demo form behavior

Open index.html in a browser. Keep all files in the same folder.
Replace profile.jpg with your own image file (use that exact filename), or change the
image src in index.html and about.html. Update the sample project descriptions and
technology lists to match your actual work. Add your real social links if desired.

The contact form is front-end only. It validates fields and shows a confirmation,
but it does not send an email or save submissions without a server-side service.
